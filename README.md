# 3D 跑酷游戏协作仓库

本仓库用于 Week 05 3D 游戏小组作业。当前可玩的游戏文件位于 `w05_3d_game/index.html`。

## 当前项目

- 类型：浏览器 3D 跑酷游戏
- 技术：HTML、CSS、JavaScript、Three.js
- 目标：躲避障碍、收集方块、使用角色技能并获得更高分
- 当前角色：红色、绿色
- 当前玩法：三条跑道、跳跃、滑铲、换道、粉色方块、技巧方块、技能、暂停和角色选择

## 本地运行

1. 进入 `w05_3d_game/`。
2. 用浏览器打开 `index.html`；如果浏览器限制本地模块加载，请在项目根目录启动本地静态服务器，例如：

   ```bash
   python -m http.server 8000
   ```

3. 浏览器访问 `http://localhost:8000/w05_3d_game/`。

当前版本通过 CDN 加载 Three.js。提交前应将依赖改为项目内的本地文件，以满足作业对离线可运行和相对路径的要求。

## 协作分支

- `main`：稳定、可提交版本
- `content`：游戏内容与关卡节奏
- `controls`：操作与手感
- `ui-sound`：UI 和音效
- `debug`：Bug、性能和兼容性
- `demo`：Demo 模式和宣传展示

每个人在自己的分支完成小改动，提交后通过 Pull Request 合并到 `main`。合并后由 Debug 负责人重新运行游戏。
