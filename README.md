# 3D 跑酷游戏协作仓库

本仓库用于 Week 05 3D 游戏小组作业。当前可玩的游戏文件位于 `w05_3d_game/index.html`。

## 当前项目

- 类型：浏览器 3D 跑酷游戏
- 技术：HTML、CSS、JavaScript、Three.js
- 目标：躲避障碍、收集方块、使用角色技能并获得更高分
- 当前角色：红色、绿色
- 当前玩法：三条跑道、跳跃、滑铲、换道、粉色方块、技巧方块、技能、暂停、角色选择和基础方块玩法教程

## 本地运行

1. 在项目根目录打开 PowerShell。
2. 启动本地静态服务器：

   ```bash
   python -m http.server 8000
   ```

3. 浏览器访问 `http://localhost:8000/w05_3d_game/`。

Three.js（r160）已放入项目目录 `w05_3d_game/lib/three.module.js`，importmap 用相对路径加载，离线或本地静态服务器下均可运行，不再依赖外网 CDN。注意：ES 模块在 `file://` 直开时会被浏览器 CORS 策略拦截，请按上面的本地静态服务器方式运行。

## 玩法教程

主菜单点击“玩法教程”后可选择两种教学，速度均固定为 28：

- **基础方块教程**：先显示“欢迎来到基础方块教程”，再按方块展示 4 秒、空档 2 秒、玩法提示 5 秒、对应方块练习、空档 2 秒的流程自动推进。教程包含橙黄色高墙、蓝色矮墙、紫色悬墙、粉色能量方块、左右技巧方块、跳跃技巧方块、滑铲技巧方块和悬浮方柱。展示和提示阶段玩家锁定在中间 2 道，练习阶段可按提示操作。
- **组合方块教程**：先展示两侧橙黄色高墙并引导“二段跳越过高墙”，随后练习移道接滑铲、跳跃接悬浮方柱、左移接二段跳、二段跳接右移、滑铲接悬浮续跳等无粉色方块的联动组合。碰到组合障碍时不会立即结算，而会清除并在前方重生当前组合；同一组连续失败三次后显示“别灰心，我们继续教学”，然后进入下一组。所有教学完成后显示完成提示并返回主菜单。

教程进行中可按 `Esc` 暂停，使用暂停界面的“继续游戏”恢复，或选择“返回主界面”退出。

## 固定关卡与Boss

主菜单的“选择关卡”包含 5 个固定地图关卡。前 4 关为时长约 30 秒、难度递增的预设平面跑道；障碍、奖励和技巧方块均使用固定表格，重复游玩时位置和类型不变。第 5 关先完成约 30 秒的固定地图，再进入终点 Boss 战。

Boss 是占三道的黑色方块，有红色愤怒眼睛和尖牙，会跟随玩家移动并发射大量随机先后出现、沿斜向轨迹移动的红色弹幕。Boss 弹幕共 5 轮，每轮 12 秒，轮间间隔 4 秒；弹幕密度和速度逐轮增加，同时保留多条可躲避路线。Boss 消散后播放渐黑、制作组名单、END 停留与消散，并以睁眼效果返回主菜单。

第5关选择页另有“Boss演示模式”，会自动操作角色、选择跑道、跳跃躲避并完成Boss战，自动播放通关结尾。

## 协作分支

- `main`：稳定、可提交版本
- `content`：游戏内容与关卡节奏
- `controls`：操作与手感
- `ui-sound`：UI 和音效
- `debug`：Bug、性能和兼容性
- `demo`：Demo 模式和宣传展示

每个人在自己的分支完成小改动，提交后通过 Pull Request 合并到 `main`。合并后由 Debug 负责人重新运行游戏。

## 已知限制

- 当前游戏主要集中在单个 HTML 文件中，后续可按分工拆分 JavaScript 和 CSS。
- 当前版本尚未完成作业要求的 Demo 模式。
- 教程中的粉色方块练习采用地面/空中交替的安全示范摆法，因为原需求未单独列出粉色方块练习数组。
- 只提交 `w05_3d_game/` 目录中实际需要的文件，不要提交密码、Token 或其他私人信息。

## 音效与外部资源

本游戏全部音效由浏览器 Web Audio API 现场程序合成（振荡器 + 包络），包含菜单点击、换道、跳跃、拾取粉色方块、技巧方块、释放技能和碰撞结束共 7 种提示音；没有使用任何外部音频文件，也没有 AI 生成的音频素材，无需额外授权。

右上角 🔊 / 🔇 按钮为静音开关，点击即可切换，静音偏好会保存在浏览器本地；声音在玩家首次点击“开始游戏”后才启动，符合浏览器自动播放限制。
